# Nexaform

## Project Info

Nexaform is a Vite + React + TypeScript site with a Supabase-backed admin workspace.

## Local Development

Requirements:

- Node.js
- npm

Run locally:

```sh
git clone <YOUR_GIT_URL>
cd <YOUR_PROJECT_NAME>
npm install
npm run dev
```

## Stack

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS
- Supabase
- Vercel
